Declarer Challenge - upload instructions
=========================================
1. Upload the whole contents of this folder to your GitHub Pages repository, in a folder called declarer-challenge
   (so the app opens at mikes-bridge-scorer.github.io/declarer-challenge/).
2. Open that address on your phone in Chrome, wait a few seconds, then use the menu > "Add to Home screen" (or "Install app").
   Opened from the home-screen icon it runs full screen, with no browser bar and no Claude header.
3. Each time you upload a new index.html, change the number in CACHE='declarer-challenge-v1' inside sw.js
   (v2, v3...) so phones pick up the new version.

Credits: card images are from "Vector Playing Cards" by Byron Knoll (public domain).
